# Iconos PWA

Para que la PWA funcione correctamente, necesitás crear dos iconos:

1. **icon-192.png** - 192x192 píxeles
2. **icon-512.png** - 512x512 píxeles

Colocarlos en esta carpeta (`Frontend/public/`).

Puedes usar herramientas online como:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

O crear los iconos manualmente con cualquier editor de imágenes.
